# 知证 VeriMind 局部流程图

用于设计报告、技术说明和汇报材料中的局部业务流程图。开始前阅读项目规范：

- [流程图视觉规范](../../../docs/brand/流程图视觉规范_v0.1.md)
- [已确认的 v0.9 SVG 参考图](../../../docs/architecture/跨源事实核验_局部流程示例_v0.9_参考图紧凑重排.svg)

按用户给定的业务节点与关系作图；视觉重排不能改变流程含义。采用图标作为节点主体、名称置于图标下方，减少节点卡片和长说明。优先按“上方两个并列模块、下方一个核验或汇总模块”组织，让三个模块视觉高度接近；模块内以水平流程为主，用少量直角折线表达必要的分支和跨模块关系。

直接沿用合适的现有 SVG 图标。项目品牌标志、产品界面及通用模块图仍遵循品牌图标规范；不要把本地流程图插画扩展成新的全局图标集。需要新增复杂节点时，先检查项目品牌资产与批准的参考素材，再选择与用户要求相符的方案。

交付时保留可编辑 SVG，并导出 PNG 预览。目视检查图面平衡、文字溢出或重叠、图标大小、连线穿字/穿图标、箭头终点、裁切和实际展示尺寸下的可读性；不能只凭 SVG/XML 合法就判断图已完成。具体颜色、尺寸建议和检查清单以项目视觉规范为准。
