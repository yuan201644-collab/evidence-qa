# 跨源边界挑战 v0.1

日期：2026-10-01。仅用于合成工单—合同链的定向工程检查，不是独立留出题或自然业务语料。

- `retry_documents/HT-EVAL-001.md`：九个办理流程章节含首轮查询词但不定义时限；第十节定义受理至服务恢复的八小时限值。真实解析、切片和 BM25 中首轮前八条无时限，定向补查找回第十节。
- `missing_documents/HT-EVAL-001.md`：不定义限值，验证两次检索后停止，不允许造时限。

只通过显式环境变量接入辅助进程，不覆盖开发文档或原七题资料。样例按现有策略构造，不据此报告普遍召回率提升。

完整复现入口是 `eval/cross_source_verify.ps1`：仅创建自身临时数据库/辅助 API，随机密码不落文件，结束时清理自建服务并保留报告。实际数据库故障包括认证拒绝、只读拒写和临时锁等待，不模拟连接器抛错；诊断 UPDATE 不进入在线工具。

不运行数据库时，可用 `.\.venv\Scripts\python.exe -X utf8 eval/cross_source_boundary_runner.py` 执行真实检索及本机 TCP 故障。完整命令、最终结果及时间预算边界见 `docs/architecture/阶段C验证与定向修复记录_v0.2.md`。

当前 Windows 驱动即使遇到 OS 拒绝连接，也可能直到预算耗尽才返回；配置 1 秒连接超时实测约 2 秒，不能宣称严格毫秒级端到端截止。
