### 归纳出的命名规律

1. **队伍名 3–5 字，意象化、正向、可喊**：影智探微（取"见微知著"）、硅基梦想家、赋能未来。没有一个队名使用"XX大学一队"这类流水号式命名。
2. **作品名两段式**：`技术/场景描述 —— 产品名`，如《AI赋能的产业园区精准招商辅助平台——招商智脑》。副名短、好记、可单独传播。
3. **智能体类赛题偏爱"对象 + 角色"式命名**：招商智脑、防诈智能卫士——先说要给谁干什么，再给一个拟人化的能力名。
4. **算法赛道偏工程化直陈**：《混合空域融合飞行程序优化与仿真验证》，无修辞，只讲做了什么。
5. 名字里**不出现"第一/领先/超越"等比较级**——获奖名单整体是描述型而非宣传型。

## 三、项目名的取舍

现有产品名 **知证 VeriMind** 本身已符合第 2 条规律（"知证"=答案回到可核验来源），因此不建议另起新名，只需补齐"两段式"的副名部分。

### 方案 A（推荐）
**《多源政企数据的可核验问数智能体——知证 VeriMind》**

- 前半句交代场景与能力（多源、政企、可核验、问数），后半句是可传播的副名，完全贴合获奖名单的版式。
- 与 `docs/品牌与技术命名_v0.1.md` 的对外口径一致，不改任何既有名称。
- "政企"比"政采"更宽，避免把作品限定在政府采购一个口径上（开源赛道评审关注可复用性）。

### 方案 B
**《知证 VeriMind：可逐条核验证据链的问数智能体》**

- 把最有辨识度的差异点（逐条核验）放到最前，适合强调技术报告的"证据账本"章节。
- 缺点：冒号式命名在获奖名单里少见，偏论文标题。

### 方案 C
**《知证·证据链问数智能体》**

- 最接近"招商智脑""防诈智能卫士"这类短名，适合做视频片头与 PPT 标题。
- 缺点：信息量少，"多源"和开源贡献体现不出来。

### 不采用的写法
- 含"精准""智能体平台""一站式"等泛化词——与"简单部署、换行业包装不算完成"的评审口径相撞。
- 含"图谱增强""KAG"——KAG 仍是研究支线且未接入默认链路，写进作品名会被追问；应放在技术报告"下一步"章节，不作为作品标签。
- 含"超越 RAG""第一"——与项目一贯的"不夸大"纪律冲突。

## 四、队伍名的取舍

硬约束：已知已被占用的名字包括影智探微、硅基梦想家、赋能未来；应避免任何"XX未来""XX智"结构的近似名。

### 方案 1（推荐）据证求是
- 化用"实事求是"，四个字同时说清方法（据证）与态度（求是），对政务/采购这个场景非常合身，答辩自我介绍顺口。
- 与产品"知证"同源，评委听完作品名再听队名不会觉得两张皮。
- 风险：偏严肃，缺少记忆点；如需活泼版可用方案 2。

### 方案 2 有据可循
- 成语直用，含义与产品完全一致（每条结论都能循到出处），4 字、好写、好念。
- 风险：成语类队名使用率高，存在与其他队伍重名的可能；报名后以组委会名单为准。

### 方案 3 循证三士
- "循证"（循证医学式的方法论）+ "三士"点出三人规模，有辨识度、不易撞名。
- 风险：略带文气，"士"字在工科答辩场合可能被读成玩梗。

### 方案 4 证链小组
- 最保守，直接说明做的是证据链；适合不想在队名上花心思的情况。
- 风险：平淡，且"小组"显得像课程作业。

### 英文（如报名表要填）
- 产品：VeriMind
- 队名：Provenance（"来源/出处"，与中文"据证求是"同义）；或直接写 VeriMind Team

队名与作品名一旦确定，需要同步的位置（漏一处就会在材料里出现两个名字）：

2. 技术报告封面与页眉
3. 演示视频片头（建议 3 秒内出现：作品名 + 队名 + 一句话定位）
4. 答辩 PPT 首页与结束页
5. `README.md` 首行标题与 `docs/品牌与技术命名_v0.1.md`（如需在"展示规则"里补一条队名说明）
6. **界面截图仍不得出现队名与人名**——`docs/界面截图操作说明_20261018.md:122` 已规定"交付物不做身份标识"，队名只出现在报名与封面类材料中。
