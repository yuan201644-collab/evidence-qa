# 跨源架构新题包交接清单 v0.1

用途：把当前代码与开发回归交给未参与本轮实现的人编制、核验一批全新题，作为后续正式对照的输入。此清单不是 Gold，也不包含标准答案。

## 交接给题目编制者

请仅使用冻结后的业务规则和数据格式编制全新题，不读取本轮开发回归的回答、Gold 或历史评审意见。题目必须使用新的工单、设备、客户和合同组合，不能只是旧题换编号；运行包只放题目、结构化数据、合同文档、schema 和哈希清单。

题型至少覆盖：

- 唯一受控映射且能完整回答；
- 映射悬空、设备缺失、关键事件缺失或倒序；
- 客户冲突、未定义映射依据、多合同歧义；
- 映射有效期与合同有效期分别失效、端点等于时限；
- 合同明确未约定、首轮召回不足需补查、文档范围或特别约定冲突。

另置包外受控 Gold 与逐题独立事实复核材料。Gold 必须由未运行系统的核验者从 CSV、事件表和合同原文独立重建；引用片段必须是文档真实子串；负证据必须明确表名、过滤字段和值及实际行数。

## 交接给独立核验者

只读取运行包和原始合同/结构化数据，逐题重建工单→设备→映射→合同→事件关系，核对双有效期、客户、合同状态、条款范围和时长。不要读取系统回答、配对密钥或作者自审版。输出独立核验报告，并记录任何无法从冻结材料确定的题。

## 交接回运行者

需要以下材料后才能运行：

1. 无 Gold 运行包路径与 `SHA256SUMS.txt`；
2. 包外 Gold、核验报告和各自 SHA-256；
3. 题包编制者与核验者的角色声明；
4. 运行包数据导入/只读数据库快照和文档索引；
5. 本文件、`跨源架构事实核验匹配对照预注册_v0.1.md`、代码和模型配置的冻结哈希。

运行者在正式原始回答生成前不得打开 Gold。若题包角色隔离、哈希、只读权限、题目覆盖或文档引用核验任一项不满足，先退回补齐，不启动正式对照。
