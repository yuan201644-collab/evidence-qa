# 跨源 A/B 可观测性与判据修订记录 v0.1

日期：2026-10-04  
范围：新留出集编制前修正 A/B 新臂的内部早停轨迹，并校准最终引用与中间 trace 命中的一致性判据。此记录不评价任何历史回答或效果。

## 发现

静态复核发现，A/B 的新臂执行私有事实计划，而不是独立跨源演示工具。此前它不会输出冻结评测所需的早停原因码；关键事件任务与文档任务的依赖也未阻止“事件不受支持时仍先检索合同”。另外，RAG trace 保留召回/重排候选，最终引用通常只是候选子集；评分器此前要求两组完全相等，与工具对 `trace.hit`（步骤命中）和最终 `refs`（实际引用）的既有语义不一致。

## 本轮更改

- 私有 `FactDecision` 增加白名单原因码校验，禁止受支持事实同时带早停码。
- 执行器只记录首个真正阻断依赖的早停原因；早停 `hit` 只取本轮账本中已登记的引用。摘要输出 `status=not_determined`，单独记录具体原因码。
- 合同文档任务现在依赖受控映射和事件耗时事实；事件倒序时不调用文档工具。
- 映射原因码仅由真实 SQL 结果行和确定性校验导出。空结果、设备缺失、事件缺失及其他尚无完整负面引用接线的情形不声称为已支持早停。
- 新臂为真实的一次混合检索调用增加稳定 trace 投影；仅对可回答条款题使用，不把一次检索冒充两次有界补查。因此新留出集明确不含 `bounded_not_found` 题。
- 评分器的引用一致性改为 `final refs ⊆ union(trace.hit)`：最终引用必须在真实 trace 命中中出现，但未被最终引用的中间候选仍可保留。v0.4 原协议不覆盖；新增 v0.5 补充协议并要求新运行重新冻结。
