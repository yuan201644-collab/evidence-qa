## 3. 关键叙事变化

| 原有容易被误读的说法/表达 | 本次处理 | 原因与依据 |
|---|---|---|
| “去掉任一环节，整体方案就无法成立”可作为创新证明 | 改为机制、目标失败类型、同条件对照和成本/适用边界 | 模块不可替代只说明依赖关系，不证明机制产生效果 |
| 五层图承担完整架构叙事 | 五层保留作系统组成/部署图，另加数据准备、在线问答、离线评测三种视图 | 分别回答组件位置、运行时决策、效果验证 |
| 同时调SQL、RAG/图检索即跨源融合 | 拆为对象对应、口径对齐、事实-证据关联、失败控制 | 多工具并用不等于同一业务对象/同一指标已关联 |
| 调用trace、工具命中、答案引用可以互换 | 明确区分调用记录、候选命中、事实记录、最终证据关联 | 现有契约字段不能表达逐事实支持关系；需团队评审适配 |
| 带重试的全流程可称DAG | 仅单次依赖计划可为DAG；含重试流程有回边 | 澄清计划拓扑与运行状态机的不同 |
| KAG结果可概括为“图谱没用/总是更优” | 按阶段、题集、证据指标和时延分开记录 | 阶段三和阶段四题集与判据不同，阶段四仅4题重复三次 |

## 4. KAG报告数字核对口径

依据最新报告 `D:\kag\stage4_unseen\reports\KAG接入评估实验报告.md`：

- 阶段三：30道双跳留出题，每题单次；项目多跳人工阅读正确26/30、双文档引用25/30、平均9.41秒/P95 13.22秒；KAG向量正确16/30，另有3题正确但带无关候选细节，引用3/30、平均31.38秒/P95 50.14秒；KAG图谱正确30/30、引用3/30、平均28.42秒/P95 35秒。人工阅读不等于盲审，答案正确与双证据引用分开。
- 阶段四：4道合成三跳题、每模式3次，共每臂12次运行。项目普通RAG关键词命中0/12、完整三事实引用0/12、均时4.63秒；项目多跳0/12、0/12、11.30秒；KAG向量12/12、12/12、66.47秒；受控图谱混合12/12、9/12、63秒。关键词与字符串/来源检查不等于独立语义评审，不能称12道独立题或泛化准确率。
- 阶段四官方原版混合另列：关键词12/12、完整三事实引用0/12、45.76秒；配置并未与受控臂完全一致，不能当作同条件算法比较。

两个阶段不合并成单一总分。阶段三报告答案正确率与证据引用，阶段四小样本报告关键词及三事实引用判据；证据正确和答案文字正确不可互相替代。结论限于对应数据/配置，不能宣称KAG普遍优于或劣于现有链路。
