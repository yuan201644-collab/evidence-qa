# 项目整体流程图 v0.2 使用与实现核对说明

日期：2026-10-12。状态：按当前工作区实现整理的项目流程视图，不是功能验收证书。

## 1. 图的范围

借鉴导师参考材料的分区标题、模块卡片、配色及来源与输出展示方式；内容依据本项目代码重新组织。图包含独立数据准备、在线编排、SQL 工具、文档工具、显式跨源实验路径、统一输出、横向支撑和独立评测。

图中六个分区是阅读分区，不改变项目既定的五层系统结构。交互层对应分区二和四；编排层对应分区二及三 C；工具层对应三 A/B 及相关核验节点；数据层对应分区一；模型层见分区五。离线评测是独立验证流程。

## 2. 关系与能力边界

- 数据准备独立于用户请求；正常作答使用准备好的结构目录和文档索引，不必每题重复 OCR。
- 路由选择对应的执行路径，并非所有工具固定并行。普通单源问题直接汇入统一输出。
- 跨源事实计划当前按开关显式启用，工单—合同是已实现的专用场景；任意业务的通用自动事实规划不在已实现声明内。
- 跨源 C 路径复用 SQL 工具 A 和文档工具 B。桥接关系和事件前置事实不受支持时，依赖它们的后续任务可跳过；不将名字相似或检索命中直接视为事实成立。
- SQL 校验、执行失败按是否可修复决定重写；连接、权限等不可修复问题不靠无限重写解决。重写的 SQL 再次校验后才可执行。
- 文档单轮和多跳由当前配置选择。图中多跳回路属于多跳路径，不表示每题自动启用多跳。RAG 的约束生成与引用解析不等同于通用的逐事实真实性证明；显式事实核验在 C 路径内。
- 文档坐标仅在真实可得时支持几何高亮；页码、章节和字符偏移不能伪装成像素坐标。
- KAG 真实接入尚未进入主项目默认链路，故采用紫色虚框；当前 `GRAPH_BACKEND=kag` 注册模拟工具，不能当作真实接入证据。图未画出已实现的 KAG 调用箭头。
- 离线评测结果反馈到后续版本改进；标准答案不进入在线生成或检索索引。本图不展示未经核实的全量完成率或性能结论。
- 提前停止是按实际任务和业务条件处理，不承诺所有实验题在检索之前停止；CS18 已记录的晚停控制流偏离应继续由实验报告披露。

## 3. 主要依据

| 图中内容 | 实现依据（仓库相对路径） |
|---|---|
| 路由、上下文、澄清 | `app/orchestrator.py`、`app/memory.py`、`app/clarifier.py` |
| 要素识别、定位、关联、校验、执行 | `app/nl2sql/normalizer.py`、`linker.py`、`join_planner.py`、`pipeline.py`、`validator.py`、`semantic_validator.py`、`executor.py` |
| 文档接入与目录、切片 | `app/rag/ingest/loader.py`、`normalize.py`、`ocr.py`、`toc.py`、`chunker.py` |
| 文档索引与召回、重排 | `app/rag/retrieval/indexer.py`、`pgvector_store.py`、`retriever.py`、`fusion.py`、`reranker.py` |
| 单轮、多跳与引用 | `app/rag/answer.py`、`app/rag/multihop.py` |
| 跨源事实计划与核验 | `app/fact_planner.py`、`app/fact_executor.py`、`app/cross_source_fact_plan.py`、`app/evidence_ledger.py`、`app/tools/cross_source_policy.py` |
| 公共结果和来源字段 | `app/contracts.py`、`app/main.py`、`app/result_sets.py` |
| 用户呈现 | `web/src/views/WorkspaceView.vue` 及其对话、引用与证据组件 |
| 测评覆盖与要求 | `docs/reference/赛题八_题面原文.txt`、跨源运行/评分工具与已封存实验记录 |

## 4. 文件与重建

- `项目整体流程图_v0.2.png`：用于查看、分享及插入报告的高清图片。
- `项目整体流程图_v0.2.svg`：矢量源图，放大不模糊。
- `项目整体流程图_v0.2.html`：浏览器查看，可切换缩放。
- `项目整体流程图_v0.2.cjs`：可复现生成器。正文和关系修改应在此文件进行，再重建。

在项目根目录运行：

```powershell
node .\docs\architecture\项目整体流程图_v0.2.cjs
```

PNG 由浏览器使用系统中文字体渲染 SVG 后导出。整图细节较多，报告中宜使用横向页；正文可按数据准备、在线处理、跨源核验分区截取，保留整图于附录。
