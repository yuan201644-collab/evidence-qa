# 跨源新一轮独立留出集交付清单 v0.2

日期：2026-10-04。此版补充并覆盖 v0.1 的运行包格式及开跑审计项；角色隔离、覆盖范围、Gold 内容、题目去重等要求继续沿用[交付清单 v0.1](跨源新一轮独立留出集交付清单_v0.1.md)。本清单与[新旧流程对照预注册 v0.2](跨源问答新旧流程对照预注册_v0.2.md)配套。  
用途：交给未参与本轮事实核验实现和 ARC-01–ARC-12 题集工作的独立编题者与复核者。当前没有符合本清单的新题包。

## 1. 独立角色不变

编题者、Gold 独立复核者、运行者、两名盲审者、trace 技术审计者须按 v0.1 的角色隔离执行。运行者只接触运行包和独立复核 PASS 结论，不接触 Gold、作者说明、答案密钥、A/B 配对信息。若人手不足以满足角色分离，须降低结论强度，不可称独立盲审或未见集。

## 2. 运行包格式（运行器严格白名单）

```text
<runtime-dir>/
  questions.jsonl
  SHA256SUMS.txt
  data/
    schema.sql
    load.sql
    schema_meta.json
    schema_meta.descriptions.zh.json
    documents_manifest.json
    structured/
      equipment.csv
      contracts.csv
      contract_equipment.csv
      work_orders.csv
      work_order_events.csv
    documents/
      <contract-id>.md
```

不要在运行包内附 `README.md`、`AUTHORING.md`、出题过程、分类/能力标签、评分说明、Gold、答案、密钥、盲审表或复核意见。日期包含端点、时区、事件定义、状态语义等必要口径须写进公开 schema/字段描述和合同原文，不以可能泄露逐题答案的编题说明作为运行输入。运行器拒绝白名单外成员，任何内容要新增都需先修订协议和运行器，再重新独立复核并冻结。

`questions.jsonl` 每行必须严格为 `case_id`、`work_order_id`、`question` 三字段。运行集建议 12–16 道新题，且为新业务组合，不得将已曝光题换编号或数值后当新题。结构化 CSV 五表必须齐全，合同 Markdown 至少一份；CSV 列顺序须与 `schema_meta.json` 完全一致，类型、主键、空值和表行数定义无歧义。

清单 `SHA256SUMS.txt` 覆盖上述所有成员、不含自身；清单文件本身的 SHA-256 通过项目外只读渠道单独锚定。Gold 和独立复核报告存放在隔离的受控目录，绝不放进 runtime zip，也不和 runtime 共用对运行者可见的交接链接。

## 3. 新增开跑审核项

Gold 复核通过后，数据保管人还需完成：

- 运行包实际文件集合与 SHA 清单完全一致，无未登记文件；外部锚点确认无误。
- 目标数据库导入后按 CSV 逐表逐行核对，不能只核行数；记录 CSV 与数据库各表行数和内容哈希。
- 使用无业务表/向量表写权限、无目标 schema `CREATE` 权限的专用只读账户；运行器再以只读事务连接。权限预检不通过，不运行。
- RAG 索引仅在计分前预建；索引文档 ID 集合与运行包文档文件名精确相等。问答前后复核五张表、分块、向量和文档元数据快照。
- `documents_manifest.json` 每项只含 `id`、`file`、`title`、`category`；文件 ID 必须与文档主文件名一一对应。旧路由/标准化/SQL 路由信号都必须读本题包元数据，不得混入项目默认库或默认语料清单。
- 在运行前登记源码/依赖、实际本地嵌入和重排模型逐文件哈希、LLM 服务端点身份/模型名/参数、协议哈希、随机种子、两臂顺序和数据库/索引快照。远程对话模型权重如不可取得哈希，明确记作不可得，不可把模型名冒充权重哈希。
- 显式冻结 `APP_TIME_ANCHOR` 日期解析基准，两臂同值；不可读取运行机器当前日期作为隐式变量。
- 运行登记文件及结束封存清单的 SHA-256 均由保管人复制到运行目录之外的独立只读/版本化位置。目录内自生成的哈希副本不视为独立锚点。
- 盲审稿必须从已封存原始答案生成；验证每题恰有两臂结果及原文/封存哈希一致。匿名稿不含工具 trace、组别、运行次序；独立技术审计者单独检查原始 trace。

## 4. 当前可执行工具与当前状态

- 正式对照运行器：`eval/cross_source_heldout/tools/run_architecture_comparison.py`。模式为预检、生成工作区外的一次性冻结登记、验证外部登记后计分；数据库连接只通过 `ARCH_COMPARISON_DSN` 环境变量传入。
- 匿名盲审稿生成器：`eval/cross_source_heldout/tools/prepare_architecture_blind_review.py`。必须提供外部封存清单哈希；匿名表和组别密钥分开写，密钥路径必须在项目外。
- 可用的 ARC-01–ARC-12 运行包已经曝光，只用于接线烟测或回归，**不可**作为此新留出集。
- 当前没有由独立人员编制并复核通过、符合上述白名单的新 runtime；没有有效新旧流程计分结果或盲审结果。任何协议/代码实现检查都不是系统效果证据。
