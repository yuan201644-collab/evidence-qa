# 跨源业务规则与比较流程提案 v0.1

日期：2026-10-06  
状态：第二步草案，供团队审阅；未冻结、未回写历史题集或 Gold。

## 1. 目的

跨源问答不能把 `contract_equipment` 中出现的一行记录直接当成“适用合同”。本文件把设备—合同映射依据、适用范围和比较流程写成可见规则，供事实核验流程和普通参考流程共同读取。规则未明确时，系统应保留不确定性并限定回答，不把“未定义”改写成“业务上明确禁止”。

## 2. 当前规则范围

本规则只覆盖“工单 → 设备 → 合同映射 → 合同文档 → 事件时长”的合成演示场景，不代表任意行业或真实生产系统的合同法务规则。

### 2.1 映射依据状态

| 状态 | 当前列入的依据 | 系统处理 |
|---|---|---|
| `allowed`（受控） | `explicit_equipment_schedule`、`attached_asset_schedule`、`signed_asset_register`、`signed_acceptance_record` | 可进入客户、双有效期、合同状态和文档范围核验；仍需唯一映射，不能只凭依据通过。 |
| `undefined`（未定义） | `field_email_note`、`dispatch_annotation`、`provisional_visual_check`、`equipment_name_guess` 以及规则表未列出的新值 | 不宣称合同关系已成立；输出“映射依据未被当前业务规则确认受控”，记录实际映射行；不引用合同条款作为已适用条款。 |
| `denied`（明确不允许） | 当前没有由团队签字确认的值 | 暂不新增。只有拿到可追溯的业务制度来源后，才可把某个值列为明确不允许。 |

这一区分解释了为什么 `equipment_name_guess` 和 `field_email_note` 不能直接加入允许名单：前者不能证明编号关系，后者在现有资料中没有定义其法律/业务效力。当前安全早停原因码 `mapping_basis_unapproved` 表示“未确认受控”，不等价于“已证明禁止”。

### 2.2 适用合同的必要条件

即使映射依据为 `allowed`，仍必须同时满足：

1. 设备编号是结构化关联键，设备主数据存在；
2. 映射候选唯一，或业务规则明确给出优先级；
3. 设备客户与合同客户一致；
4. 映射有效期和合同有效期分别覆盖工单日期，端点包含；
5. 合同状态为当前规则认可的生效状态；
6. 合同文档原文能确认设备范围和所问时限。文档条款存在例外/优先级而当前解析器不能确定时，必须限定回答。

## 3. 两套比较流程

### 3.1 普通 SQL＋文档参考流程

当前实现采用匹配参考臂 `matched_reference_ablation`：复用同一事实任务模板、NL2SQL、RAG、数据库、文档和模型配置，仅关闭跨源确定性核验。它可以查询工单、设备、映射、合同和事件，检索合同原文并计算时长；但不启用客户冲突早停、映射依据受控校验和多合同歧义拦截。它必须仍然输出用户所问的适用合同、实际时长、约定时限和是否满足；不得把“只返回 SQL 行”当成完整回答。历史 `old_workflow` 仍保留为旧路由诊断，不作为新一版公平比较的参考臂。

### 3.2 事实核验流程

事实核验流程在上述工具之上增加事实依赖、证据账本和确定性跨源核验。候选结果只有在编号、客户、双有效期、状态、文档范围和事件口径均得到支持后，才可形成肯定结论；阻断条件则输出已支持事实、阻断原因和行级/文档级证据。文档首次检索不足时最多做一次策略变化明确的补查，并在轨迹中记录两次真实调用。

### 3.3 比较口径

两套流程共享题目、数据快照、文档、模型端点和工具版本；不强行配平调用次数。主指标是题级正确性与证据完整性，另报过度肯定回答、过度拒答、运行错误和实际调用次数。若要归因某个单独机制，另开一次只移除一个机制的消融实验，不能从整流程差异直接推出单模块贡献。

代码入口：`eval/cross_source_heldout/tools/architecture_arms.py::build_matched_reference_and_fact_arms`。它不替换历史 `build_old_new_arms`，避免覆盖已有实验口径。

## 4. 当前未冻结事项

- 普通参考流程需要在正式新题运行前完成“可答题完整输出”的独立实现和单测。
- 本文件不是 v0.13 历史 Gold 的修订；历史结果继续按原判据保留。

## 5. 验证动作

规则冻结前至少检查：一个受控唯一映射可答；一个未定义依据拒判；两个有效合同不任选其一；客户冲突、映射过期和合同过期分别阻断；合同明确未约定时限时引用文档后拒判。所有检查都要使用真实执行轨迹，不能用模型自述或标准答案回放代替。
