# 队名候选池 v0.1（据证求是 同风格扩写）

日期：2026-10-27  
状态：候选池，供团队挑选。作品名仍按 `命名方案_项目与队伍_v0.2_20261024.md` 的方案一暂定。

## 0. 这一批的共同风格

「据证求是」能被接受，是因为它同时满足四点，挑新名字时按这四条筛：

1. **四字，读起来有分量**，不靠生造缩写；
2. **化用成语或熟语**，评委零解释成本；
3. **字面就在说方法**（证据、核验、追源），不是空泛的正能量词；
4. **不含比较级**，不承诺"最好"，只承诺"怎么做事"。

下面 12 个分三组：讲规则、讲方法、讲巧思。

## 1. 组一｜把产品规则直接当队名（最有冲击力）

### 无证不答 ★
- 字面：没有证据，就不作答。
- 为什么合：这不是修辞，是我们系统的真实行为——`app/evidence_ledger.py` 里"证据不足"是一个独立状态，编排器在证据不足时确实会不给结论。队名等于把一条工程约束说成一句队训。
- 最大优势：独一无二。"据证求是"仍属成语系，同风格的队伍会撞；"无证不答"基本不会撞。
- 风险：单看像"拒绝服务"。答辩时准备一句化解——**"不答，是因为证据不足时给一个答案，比不给更危险。"** 这句话还能顺势带出有界求证（BoundedVerify）。
- 撞名概率：极低。

### 有问必证 ★
- 字面：化用"有问必答"，每一个问题都要证。
- 为什么合：前半截是业务（问数），后半截是方法（证），一句话说完我们是干什么的。
- 最大优势：一听就懂、好记、好念，做视频标语也顺（"有问必证，有证必溯"）。
- 风险："必"字略强，若被追问是否每问都证到字，需按实测口径回答（单源文档 14/14，多跳引用完整度另有数据）。
- 撞名概率：低。

### 不证不立
- 字面：化用"不破不立"，没有证据就不下结论。
- 为什么合：像宣言，态度鲜明，适合答辩开场第一句。
- 风险：略空，不如前两个具体；单独看不知道做的是问数。
- 撞名概率：低。

### 言必有据
- 字面：成语，说话一定有根据。
- 为什么合：成语原样，分量足，严肃，和"据证求是"同一档次；比自造词更稳。
- 风险：成语队名使用率偏高，可能与其他队重名；且不体现"问数"。
- 撞名概率：中。

## 2. 组二｜讲方法、讲追源（学院派）

### 循证究源
- 字面：循证（循证医学式的方法论）＋究源（寻根究源）。
- 为什么合：准确保达"先取证、再追到原始出处"这条主线，学术味重，适合技术报告署名。
- 风险：偏文气，视频里念出来不够响。
- 撞名概率：低。

### 证源溯流
- 字面：化用"溯流穷源"，从答案一路回溯到源头。
- 为什么合：和产品名"知证"呼应，且画面感强（一条链往回走）。
- 风险：四字里三个字是"源/流"意象，略绕；口播不易一次听清。
- 撞名概率：低。

### 据实以证
- 字面：依据事实去举证。
- 为什么合：最平实的一种说法，几乎不会有歧义，适合保守选择。
- 风险：平淡，记忆度一般。
- 撞名概率：中。

### 循证立言
- 字面：化用"立言"（三不朽之一），以证据立论。
- 为什么合：把"给结论"这件事抬到"立论"的高度，适合强调答案要能站得住。
- 风险：文气最重，"立言"对工科评委偏生僻。
- 撞名概率：低。

## 3. 组三｜讲巧思、讲传播（风险与记忆点并存）

### 拨云见证
- 字面：谐音"拨云见日"，拨开迷雾看见证据。
- 为什么合：把一个抽象机制（在长文档里定位到那一段）变成画面，视频片头很好用。
- 风险：谐音梗，严肃场合可能被读成抖机灵；与工科答辩的调性略有偏差。
- 撞名概率：低。

### 事必有证
- 字面：每件事都有它的证据。
- 为什么合：通顺、稳、不像口号，比"言必有据"多一点"事"的具体感。
- 风险：无亮点，容易被忘。
- 撞名概率：中低。

### 一证到底
- 字面：化用"一查到底"。
- 为什么合：有力度，暗示不放过任何一跳。
- 风险：偏口号，且"到底"暗示穷尽，而我们的检索其实是有预算边界的（BoundedVerify 明确会早停）。
- 撞名概率：低。

### 正本清源
- 字面：成语，从根上纠正。
- 为什么合：字面含义与"溯源核验"高度一致。
- 风险：**语境风险最大**——这个词在新闻里多用于整治、反腐，放进 AI 竞赛会显得文不对题甚至浮夸。
- 撞名概率：高。

## 4. 明确不建议

- **见微知证**：明显借自第七届获奖队"影智探微"，评委若有印象会认为是蹭名。
- **XX未来 / XX智 / XX先锋**：与"赋能未来"等已获奖队同构，且属正能量词，不含信息。
- **铁证如山 / 一锤定音**：暗示绝对正确，与"证据不足就不答"的产品规则直接冲突。

## 5. 排序建议

| 排名 | 队名 | 一句话理由 |
|---|---|---|
| 1 | **无证不答** | 唯一把工程约束变成队训的名字，不撞名，且天然引出有界求证的故事 |
| 2 | **有问必证** | 最好念、最好传播，业务与方法一句话说完 |
| 3 | **言必有据** | 成语底子，零风险，但记忆度一般 |

若想要"稳"就选言必有据；想要"被记住"就选无证不答；想要"好传播"就选有问必证。

三个名字都建议配一句副标语放在视频结尾：**"无证不答，有证必溯。"** 这句可以复用到 PPT 结束页。

## 6. 团队自选评估：证本清源

团队提出「证本清源」（改自"正本清源"）。评估如下，结论是**可用，但要接受两个代价**。（2026-10-27 已改为「“证”本开源」，见第 9 节；本条保留作决策记录——第 1 条口播代价在"开源"版本中已消失，第 2 条"证本"需补义仍然存在。）

### 立得住的地方
- 字面方向完全正确：以证据为本、追溯到源头，正好对应"答案回到可核验来源"这条主线。
- 与产品名"知证"同字，"证"字有呼应，四字也有分量，比"拨云见证"更严肃。
- 避开了"影智探微"这类蹭名风险，也没有比较级。

### 三个代价
1. **口播零区分度**。"证"与"正"同为 zhèng、同为四声，只靠听完全无法分辨。报名点名、主持人念名单、答辩口头自我介绍这些场合，评委听到的就是"正本清源"——名字的差异只在纸面上成立。
2. **语法上是借来的**。原成语"正本清源"是两个动宾并列（正其本、清其源）；换成"证"后，"证本"不是一个成立的动宾（"以证据为本"是读者自行补出来的意思）。评审里只要有人较真，就要花一句话解释。
3. **一字之差，录入与校对易出错**。报名系统、报告封面、获奖名单回执都可能被打回"正本清源"，越到后期越难改。

另外，"正本清源"的整治/反腐语境仍会渗进来，这是原词自带的。

### 如果要保留"以证据为本＋追溯源头"的意思，两个更顺的改法
- **证本溯源**：同样是四字、同样以"证"起头，但"证本"与"溯源"两个动宾都通顺；且后半句与"清源"不同音，口播能区分。**推荐指数高于原案。**
- **以证为本**：最直白，"以人为本"的结构，零歧义，但口号感重、不体现"溯源"。

### 结论
若团队喜欢这个名字的语义方向，建议用**证本溯源**替代**证本清源**：保住了"证"字与"本/源"的意象，去掉了同音与语法两处硬伤。若坚持用"证本清源"，至少做到三点：报名系统录入后截图核对、报告封面在队名旁加一行小字释义（如"以证据为本，溯其源头"）、答辩口播时配字幕。

## 7. 高分队伍实际怎么起名（2026-10-27 补）

团队提出"队名不必与项目强关联"，据此重新采集获奖队伍名（官方名单均为 PDF 无法解析，改从各校喜报正文取）。已核实的 8 个真实队名：

| 队名 | 赛事 / 奖项 | 与项目的关系 |
|---|---|---|
| 瞰界者 | 第七届 智能软件创新赛 全国第一（南信大，作品《图鉴天工》） | 中："瞰"对应遥感俯视 |
| 影智探微 | 第七届 应用创新赛 全国一等奖（北林，肿瘤数智化筛查） | 中：只落在"影" |
| 硅基梦想家 | 第七届 应用创新赛 全国一等奖（山大，招商智脑） | 弱：AI 自指 |
| 卓越中欧队 | 第七届 神思杯 全国一等奖（中航大，政媒智编） | 无：直接取学院名 |
| 赋能未来 | 第八届 AI 智能体赛 本科组一等奖（无锡职大，银发金融防诈） | 无：通用正能量 |
| 智联队 | 第八届 河南赛区二等奖（安阳师院） | 弱 |
| 溯源智决队 | 第八届 河南赛区二等奖（安阳师院） | 强：与作品名直接对应 |

另有华东交大、江南大学、中飞院等多支一等奖队伍，喜报里**根本不写队名**，只列队成员——说明队名不是硬门槛，但一旦有，就要能读。

### 三种起名法
1. **机构/身份型**（卓越中欧队）：借学院或实验室名，零解释成本，最稳。
2. **意象型**（瞰界者、硅基梦想家）：3–4 字自造词，造一个动作或身份，不解释技术，最容易被记住。
3. **巧思/pun 型**（影智探微、智联队、溯源智决队）：把"智"或技术字嵌进词里，读起来像现成词。

### 三条可操作的结论
1. **队名不承担解释项目的功能**。上表里与项目"强关联"的只有一支，且是省二等奖；关联弱或不关联的反而是国一。样本小不足以推因果，但足以说明"强关联"不是加分项。
2. **判断标准是"能不能嵌进喜报标题"**。所有喜报的句式都是"（指导老师、成员）组成的 **XX队** 获一等奖"。把候选名代进去念一遍，念着别扭的就不能用。
3. **高分的多是"名词/身份"而不是"口号"**。影智探微、瞰界者、硅基梦想家都是"这是一个什么样的队"，不是"我们承诺做到什么"。

### 据此修正候选排序（原排序作废）
原第 6 节的三甲（无证不答 / 有问必证 / 言必有据）都是**规则口号型**——把承诺当队名，与高分样本的取名法不同类，且与"承诺强度不超过实测证据"的判据冲突。改为：

1. **溯证者**（身份型，对标"瞰界者"）：三字，动作+者，念着顺，含义即"追溯证据的人"，不承诺效果，与产品"知证"同族。喜报句式："由……组成的溯证者队获一等奖"——通。
2. **知证者**（身份型）：与产品名完全同字，品牌复用最省力；缺点是听起来像产品代号而非队伍。
3. **证本溯源**（巧思型，替代"证本清源"）：保留团队原本的语义偏好，但口播可区分、语法成立。
4. 规则口号型（无证不答 / 有问必证 / 言必有据）**降级为视频标语与答辩话术**，不再作为队名首选——它们更适合放在视频结尾和 PPT 结束页。

## 8. 跨赛事交叉验证：挑战杯 / 中国国际大学生创新大赛（2026-10-27 补）

为验证第 7 节的判断是否为普遍规律，补采挑战杯（第十九届）与中国国际大学生创新大赛（原"互联网+"）高分队的命名。累计 13 个真实样本：

| 队名 / 项目名 | 赛事·奖项 | 类型 |
|---|---|---|
| 瞰界者 | AIC 全国第一 | 身份型（3 字·者） |
| 影智探微 | AIC 国一 | 自造意象 4 字 |
| 硅基梦想家 | AIC 国一 | 自造意象 5 字 |
| 卓越中欧队 | AIC 国一 | 机构型 |
| 赋能未来 | AIC 一等奖 | 通用动词短语 |
| 智联队 / 溯源智决队 | AIC 河南二等奖 | 通用 / 强关联 |
| 繁星智作 | 国创赛 广西金奖 | 身份型（作品名前半） |
| 百事合「芯」 | 国创赛 金奖 | pun（引号标替换字） |
| 禾下她名，地载公平 | 挑战杯 主体赛特等奖 | 八字对仗（作品名前半） |
| 戏台新绎，人气共生 | 挑战杯 二等奖 | 八字对仗（作品名前半） |
| 屿脉共守，红线锁住生态根 | 挑战杯 二等奖 | 长对句（作品名前半） |
| 一「骑」当先 | 挑战杯 二等奖 | pun（引号标替换字） |
| RBOS——未来无人设备决策生态定义者 / 癌症判官——基于多组学数据的癌症亚型诊断系统设计 | 挑战杯「人工智能+」特等奖 / 二等奖 | 「形象名词——说明」作品名 |

### 四个新发现
1. **pun 型确实能拿最高奖，但都用引号标记替换字**。「百事合「芯」」「一「骑」当先」都是把被替换的那个字加引号，视觉上一眼和平常用法区分开。这正好化解了"证本清源会被听成、写成正本清源"的顾虑——可用 **「证」本清源** 的写法标出改写意图。但报名系统的名称字段未必接受引号（可能被过滤或记为非法字符），录入前须实测。
2. **「身份型 + 者/家/队/作」是跨赛事最高频的结构**（瞰界者、繁星智作、硅基梦想家）。它的好处是不承诺结果，只交代"我们是谁"，与"承诺强度不超过实测证据"的判据天然兼容。
3. **八字对仗是挑战杯社科类的特产**（作品名前半直接当队名），智能体/算法类作品基本不用。我们不宜采用。
4. **作品名与队名可以完全脱钩**：卓越中欧队 →《政媒智编》；赋能未来 → 银发金融防诈。反过来说，队名不承担解释项目的职能这一条，在三个赛事上都成立。

### 结论（三次取样不变，可定稿）
队名唯一硬约束是**念得顺、记得住、能嵌进喜报标题**。推荐顺序不变：**溯证者** ＞ 知证者 ＞ 证本溯源。若团队执意用原始方案，采用「证」本清源的引号写法，并在报名系统实测引号是否保留。**（2026-10-27 修订：队名已定为「“证”本开源」，见第 9 节；本节排序仅作决策记录。）**

样本局限需交代：挑战杯四支样本同出烟台大学一篇喜报，存在单校偏样本风险；国创赛两支为省赛金奖，未见国赛名单。上述规律属观察，不作统计推断。

## 9. 定稿（2026-10-27）

**队名 = “证”本开源**（当日先定「“证”本清源」，随后按赛题方向修订为「“证”本开源」）

改的理由有两条。一是**贴题**：本届是「AI+开源」主题赛，队名与赛题同词，形式审查的"主题符合性"一眼可辨。二是**说的是事实**：「开源」在我们的项目里不是形容词——`../README.md:41-42` 记着本仓库 AGPL-3.0-or-later、`contrib/` Apache-2.0，后者正是为向上游 Apache-2.0 的 OpenSPG/KAG 提补丁而选的许可；R1 已提 Issue [#758](https://github.com/OpenSPG/KAG/issues/758)，补丁 5 行，配套 17＋37 项离线断言。

意外收益：改用"开源"后与"正本清源"**不再同音**，第 6 节列的第一条代价（口播零区分度）自动消失。剩下的"证本"需补义一条仍然存在，靠引号与括注处理。

写法沿用第 8 节的引号方案——「证」加中文双引号，标出这是对"正本清源"句式（X本YY）的有意借用，视觉上与成语区分。第 6–8 节的排序与替代建议（证本溯源 / 溯证者 / 知证者等）不再作为首选，保留在此仅作决策记录。

### 必须落实的四条
1. **引号是名称的一部分**，一律中文全角双引号。不得写成英文引号、『』或省略引号。
2. **报名系统先实测**：提交前确认系统保留引号、且队名未与他人重名；若引号被过滤或超长，退回写作"证本开源"，并在封面与视频字幕首次出现处加括注（证据之证）。
3. **口播补一句**：读作"证本开源"，首次出现后补"证据的证"；与"正本清源"已不同音，字幕仍建议保留。
4. **同步位置**：报名表 → 技术报告封面/页眉 → 视频片头（3 秒内）→ 答辩 PPT 首末页 → `README.md:1` → `品牌与技术命名_v0.1.md`"参赛身份"节。界面截图仍不得出现队名与人名。

## 10. 排版对比：「“证”本开源」 vs 「证本清“源”」

两个名字只差引号位置：一个把引号放在被替换的「证」上，一个把引号放在末字「源」上、让它兼做"开源"的双关。放到实际会出现队名的三处地方比，差别比纸面推敲时明显。

### 10.1 报名表（单行文本字段）

```
参赛队名：  “证”本开源
参赛队名：  证本开源        ← 引号被系统过滤后

参赛队名：  证本清“源”
参赛队名：  证本清源        ← 引号被系统过滤后
```

**这是两条路的分水岭。** 引号一旦丢失，甲变成"证本开源"——仍是一个读得通、看得出在说什么的名字；乙变成"证本清源"——和成语"正本清源"只差一个字，读者只会当错别字，双关彻底消失，而且**乙的全部意思都押在引号上**。报名系统的名称字段是否保留中文引号无法预先保证，只能实测，而两个名字对同一个风险的耐受度完全不同。

### 10.2 报告封面（居中，队名在上、作品名在下）

```
              “证”本开源
     《多源政企数据的可核验问数智能体——知证 VeriMind》

              证本清“源”
     《多源政企数据的可核验问数智能体——知证 VeriMind》
```

视觉重量的差别：甲的引号在首字，读者第一眼就收到"这里有个改动"的信号，随后读到"开源"两字直接落地；乙的引号在末字，读者要先把前三字当成成语读完，走到最后一个字才遇到引号，是**事后揭示**。事后揭示更巧，但依赖读者肯停下来想一下——封面恰恰是评委只扫一眼的地方。

### 10.3 喜报标题（纯文本，队名与赛题名同句出现）

```
我校「“证”本开源」队在第八届全球校园人工智能算法精英大赛“AI+开源”主题赛中获一等奖
我校「证本清“源”」队在第八届全球校园人工智能算法精英大赛“AI+开源”主题赛中获一等奖
```

**这一处乙反超。** 甲与赛题名同句时出现两个"开源"，读起来撞词（「“证”本**开源**」…「AI+**开源**」）；乙的队名里没有"开源"二字，同句不撞，且"源"的双关被后面的赛题名反向点亮——读到"开源"，前面那个带引号的"源"忽然有了第二层意思。

### 10.4 口播与转述（主持人念名单、队友向别人介绍）

| 场合 | 甲 “证”本开源 | 乙 证本清“源” |
|---|---|---|
| 主持人念 | "证本开源"，三个常用词，听得懂但平淡 | 会念成"正本清源"，我们无法纠正（名单上写的就是证本清源） |
| 队友转述 | "证本开源，证据的证"，一句说清 | "证本清源，源加引号那个"——要解释才传得达，对方多半记成"正本清源" |

### 10.5 结论

| | 甲 “证”本开源 | 乙 证本清“源” |
|---|---|---|
| 抗引号丢失 | 降级后仍自洽 | 降级后变成错别字 |
| 口播 | 清楚 | 与"正本清源"同音，纠正不了 |
| 与赛题同句 | 撞词（两个"开源"） | 不撞，双关被点亮 |
| 单看 | 直白、贴题 | 巧，但要多想一步 |

甲在三个"会出错"的地方都更稳，乙在一个"会加分"的地方更好看。**建议仍用甲**：队名要被系统录入、被别人念出来，先保证它在最粗糙的场合不失真，再谈巧。乙的巧可以用一次——报告封面队名下一行小字：`——“证”本开源（取材“正本清源”，源指开源）`，等于把乙藏在甲下面。

### 10.6 附带评估：「证本亲“源”」（否决）

团队后续提出把"清"换成"亲"，取"亲到源"之意。**否决**，三条硬伤：

1. **谐音歧义转移到更坏的方向**。"亲源"与真词"亲缘"（裙带、关系户）同音。一个政企/政采数据项目，队名在答辩现场被听成"证本亲缘"，是负联想，不是巧。原方案"清源"最多被听成中性成语，这个会被听成贬义。
2. **口播问题一点没解决**。"亲"（qīn）与"清"（qīng）只差一个韵尾，多数南方口音完全不分；主持人仍然会念成"正本清源"，我们仍然无法纠正。
3. **引号丢失后塌得更彻底**。"证本亲源"不是任何现成词，读者既不会当成语，也不会当自造短语，只会认为是"清源"打错字——比乙更糟。

"亲"背后的意思（亲自核到源头，不转述二手结论）是好的，但它不该由谐音承载。留给视频与答辩做口号：**"不转述，亲到源"**。
