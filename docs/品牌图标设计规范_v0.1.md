# 知证 VeriMind 品牌图标设计规范

更新日期：2026-10-12  
适用范围：全项目视觉资产；本规范是项目要求，不限于前端。  
状态：v0.1 已落地，后续变更须同步更新源图标、总览与使用位置。

## 目标

知证 VeriMind 的项目总标志与功能图标共用一套可复用矢量图形。它以“数据来源与文档来源经过连接、核验后形成可追溯结论”为视觉主题；深蓝表示信息结构与稳定性，青绿表示连接和核验。图标用于快速识别产品和模块，不表示功能已经完成或通过验收。

## 统一视觉规则

1. **颜色**：品牌主色沿用前端语义色 `#315bc7`，深色底使用 `#254ba6`，核验强调色沿用 `#168b82`。KAG增强路线用紫色 `#80649b` 标记研究支线；不可把它用于暗示已接入默认主链路。状态颜色（成功、警告、错误）沿用 `web/src/styles/tokens.css`，不另造一套。
2. **线条与几何**：功能图标采用 48×48 画布，以圆角线描为主体、少量浅色面填突出焦点，视觉线宽约 2.6；曲线、圆角和节点大小保持一致，避免机械排布、过多交叉或拥挤叠压。不在不同模块中混用写实插画、厚重实心图标和细线图标。
3. **留白与缩放**：图形应在 24 像素的界面尺寸仍可辨认；报告与幻灯片按实际版面等比缩放，不拉伸、不裁切、不加非规范阴影。优先保留 SVG；只有交付格式不支持矢量时才导出高分辨率位图。
4. **语义**：同一模块在工作台、架构图、报告、答辩材料与项目说明中使用同一图标。需要表达“已实现、研究中、未接入”等状态时必须配文字或状态标记，不靠图标颜色单独表达。
5. **可访问性**：独立展示的图标提供中文名称或替代文本；装饰性图标标记为隐藏，不重复朗读邻近文字。图标不能取代图表标题、数据标签、来源说明或必要文字。
6. **边界**：KAG增强路线只能与“KAG 研究支线 / 尚未接入默认问答链路”等文字共同出现。不得通过图标、配色或位置暗示已完成工程接入。

## 落地位置与检查

- 前端：侧栏产品标记使用 `verimind-mark.svg`；FEVA 整体架构入口使用 `feva-architecture.svg`，架构导览中的机制卡片使用对应模块图标。`AppIcon.vue` 保留为通用交互图标库。
- 架构图与报告：引用同一目录中的 SVG。图标用于解释模块关系，不替代流程箭头、证据说明或功能状态；报告插图应在导出后检查尺寸、清晰度和图文关系。
- 项目材料：README、设计报告、技术说明、演示截图及后续答辩幻灯片按同一套图标和颜色使用；不另建平行的品牌图形。
- 修改与检查：新增或调整模块语义时，先更新本规范和图标总览，再改调用位置。检查 SVG 可解析、路径完整，运行 `web` 构建，并检查图标总览与相关图表在浏览器中的显示。
