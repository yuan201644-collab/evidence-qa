# EvoOntology 当前接入价值结论 v0.1

日期：2026-10-04。决策范围：当前 Builder `verified-v0.1` 知识包与 AdventureWorks 任务4 SQL 主链路。此结论不判断 EvoOntology 论文在其他任务/数据集上的价值。

## 决策

**当前不把整包 EvoOntology 知识或按需检索流程接入正式主链路。** 这是基于“尚未证明有稳定问答收益，且成本可见”的工程不接入决定；不是证明 Ontology 无效。

最新直接 SQL A/B 试跑中，B 的最终正确率比 A 高 2.9 个百分点，但题级配对 95% 区间为 −2.9 至 +8.6，包含零，也未达到本轮预设的 +10 个百分点工程收益门槛。知识覆盖题点估计为 +10 个百分点，但仅 10 道题，区间为 0 至 +25，仍不足以支持稳定收益。与此同时，整包知识令总词元增加 63.6%，延迟中位数增加 22.6%。

因此不能因覆盖题上的正向点估计就上线整包知识；未覆盖题没有观察到净收益，新增提示成本则发生在每条 B 请求上。当前正式链路不应为一个未确认的收益承担这些成本。

## 为什么不再跑一个小型“确认实验”

本轮已按预设路径尝试新建独立确认题，而不是把探索题改年份复用。合成的 25 题候选通过只读数据库筛查：Gold 全部可执行、非空且列契约匹配；错误变体都能与 Gold 区分。但独立静态语义盲审只有 16 题评为 valid，7 题仍有边界/近重复疑点，2 题为实质近重复。去掉疑点和重复后，完全清楚的新 covered 题数量约 10，远低于 80 题的目标，也不足以估计稳定的覆盖知识效应。

覆盖标注者在不看 Gold、数据库报告或模型结果时，将原 25 题分为 covered 13、adjacent 11、uncovered 1；含义只用于分层，不说明题目质量。最初试图盲出 uncovered 控制题的一份草稿曾意外暴露 `knowledge_relation` 字段，已标为受污染且未使用。最后使用白名单文件独立出题并用净化输入重新盲审，数据库检查也独立运行。没有为了达到样本数把近重复、结果不可区分或语义不明的题留在实验里。

根据试跑题级差值波动，要在 covered 题上可靠检出 +10 个百分点本就约需数十至上百题；现有高质量新题远不足。再跑这 10 道题最多是小样本重复观察，很难改变“证据不足”的结论，因此没有发起额外模型调用，也没有把候选题冻结成确认实验。

## 项目执行建议

1. 现阶段不改正式问答主链路，不加入默认全量知识提示，不接入全链路 C。
2. 保留当前 `verified-v0.1` 作为有来源的研究性资产；不把它描述为已提升项目准确率或竞赛得分。
3. 后续若项目积累了真实、独立、具有业务代表性的问数评测集，再按 `docs/EvoOntology任务4独立确认实验方案_v0.1.md` 重启评估。优先按真实问题分布分层，并将问题按知识概念成簇分析。
4. 只有在新题上覆盖知识的准确率达到预设增益、区间支持正效应，且按需检索能以可接受成本保留收益时，才提交正式接入提案；届时再区分整包注入、按需知识和结构裁剪各自的贡献。
