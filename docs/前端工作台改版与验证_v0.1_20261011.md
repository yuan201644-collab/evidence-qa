# 前端工作台改版与验证 v0.1

更新日期：2026-10-11。范围：Vue 问答工作台与前端请求状态处理。

## 1. 当前结果

新版已完成并接入现有问答接口。首页突出文档问答、数据查询和提问入口；回答与引用成为主画面，点击引用再查看原始证据。保留会话管理、澄清交互、查询结果分页、CSV 导出、PDF 引用定位与真实工具记录。

设计参考导师提供的知产维权页面，以及 Dify、RAGFlow、DB-GPT 等项目的工作流与证据呈现方式。采用的设计判断是：明确提问入口、突出结论、让引用可操作、按需展开详细过程。导师 HTML 是界面参考，不能据其模板宣称对应后台功能已实现。

按项目《功能清单与技术框架 v1》映射，本轮主要支撑交互 Demo 可用性 5 分、答案可解释性 5 分及演示效果 5 分。界面检查不等于已获得这些分数，也不替代问答准确率和忠实度评测。

## 2. 页面与交互

| 部位 | 现在的行为 |
|---|---|
| 首页 | 显示产品用途、两个可点击示例和自然语言输入框；示例仍经真实问答接口处理 |
| 会话栏 | 展示本地历史，支持新建、切换、重命名、置顶和批量管理 |
| 回答区 | 分清用户问题、系统回答、澄清和失败状态；引用编号直接打开对应来源 |
| 来源卡片 | 展示文档或表字段、页码或主键、引用片段；多来源可展开 |
| 证据区 | 桌面按需展开；窄屏为浮层；可关闭以恢复答案阅读空间 |
| 文档原文 | 默认适宽、允许缩放与翻页；仅在引用来源页绘制返回坐标的高亮 |
| 数据证据 | 展示来源表、字段、主键、片段及本次查询语句 |
| 处理过程 | 由返回的调用记录生成路径概览；展开查看真实输入、输出、来源数量和工具累计耗时 |
| 请求状态 | 等待计时、停止等待、三分钟超时、友好失败提示和重试 |
| 服务状态 | 定期检查后端 `/health`，明确仅表示后端连通 |

没有新增公共响应字段。页面只依据当前接口返回的引用、结果集和调用记录展示功能；没有把 KAG 或跨源核验宣传为每次请求必经步骤。

## 3. 修复的具体问题

1. **回答已返回但输入仍锁定**：提交时原始等待消息存入响应式会话后，继续修改原始对象，无法通知等待状态计算。改为更新会话内的响应式消息，成功和失败都能恢复输入。
2. **等待没有上限**：提问请求增加三分钟上限与停止等待；中止后仍保存失败问题供重试。
3. **中文输入法误发送**：选字过程的 Enter 不提交问题。
4. **同文档同页切换引用后画面消失**：同页切换保留已渲染页面，更新引用高亮。
5. **翻页沿用其他页引用坐标**：高亮只出现在该引用的原页，并提供返回引用页操作。
6. **缓存页面丢失总页数**：缓存同时记录文档页数，重新打开时可以正常翻页。

停止等待不等于服务端取消计算。为避免误导，该边界已在使用指南与前端 README 中说明。

## 4. 验证范围

### 4.1 构建与浏览器交互

执行 `npm.cmd run build`，类型检查与生产构建通过；`git diff --check -- web` 通过。

受控浏览器检查覆盖：引用展开、查询语句、处理记录、分页导出、无页码片段、PDF 同页切换与翻页、澄清、中文输入法、500 失败重试、停止等待、超时恢复、会话刷新恢复、使用指南键盘操作，以及 1920、1440、1024、390 像素宽度下的布局。受控回答明确标注为界面验证材料，不用于证明模型能力。

| 输入 | 实际接口结果 | 界面核验 |
