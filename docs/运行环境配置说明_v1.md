## 6. 模型权重（**不在代码仓库内**，需单独提供）

RAG 链路依赖两个本地模型，加载路径由 `.env` 的 `BGE_EMBEDDING_MODEL` / `BGE_RERANKER_MODEL` 指定：

| 模型 | 用途 | 体积（约） | 仓库内状态 |
|---|---|---|---|
| bge-m3 | 向量化（embedding） | 2 GB | `models/` 目录**仅含 `.gitkeep`，权重未入库** |
| bge-reranker-v2-m3 | 重排（rerank） | 2.2 GB | 同上 |

- 容器镜像构建**强制校验**二者存在（`Dockerfile` 里 `test -f models/bge-m3/config.json` 等），缺失即构建失败。
- 权重获取两条路：本地已有目录直接指路径；或经 `HF_ENDPOINT=https://hf-mirror.com` 从 HF 镜像拉取。
- `HF_HUB_OFFLINE=1` **只在权重已完整缓存后**设置，否则加载直接失败（`README.md` §7.3）。

## 8. 安装与启动

操作步骤以 `README.md` §七为准，此处只给**顺序摘要**：

```bash
# 1) 取代码
git clone https://github.com/yuan201644-collab/askdata-agent.git && cd askdata-agent

# 2) Python 依赖（uv 按 uv.lock 还原 69 个包）
pip install uv && uv sync

# 3) 本地配置
cp .env.example .env        # .env 不入库；填入 DB 口令、LLM 凭据、模型权重路径

# 4) 起数据库（注意：必须带 --env-file .env，且不要用 --project-directory .）
docker compose --env-file .env -f infra/docker-compose.yml up -d        # 业务库
docker compose --env-file .env -f infra/docker-compose.aw.yml up -d     # 加压库（可选）

# 5) 起服务
uv run uvicorn app.main:app --reload        # http://127.0.0.1:8000
```

> **第 4 步的两个坑（实测）**：
> ① compose 默认只在**项目目录**（即 `-f` 文件所在目录 `infra/`）找 `.env`，而本项目 `.env` 在仓库根
> → 必须显式 `--env-file .env`，否则报 `POSTGRES_PASSWORD is missing a value`。
> ② **不要用 `--project-directory .` 代替**：它会把 `./initdb`、`./healthcheck` 的挂载基准改到仓库根，
> Docker 会静默建空目录挂进去，表现为**容器 Up 但 healthcheck 失败（unhealthy）**。

`Dockerfile` 提供整栈容器化路径：`docker compose up`（前端构建 → Python 运行时 → 单端口 8000）。

## 9. 这份清单如何重新生成（可复现）

依赖表不是手抄的，可由锁定文件重新导出，用于核对：

| 数据 | 来源 | 提取方式 |
|---|---|---|
| Python 直接依赖 | `pyproject.toml` `[project].dependencies` | TOML 解析 |
| Python 全量版本 | `uv.lock` 的 `[[package]]` 段 | TOML 解析，取 `name` / `version` / `resolution-markers` |
| 前端依赖 | `web/package.json` + `web/package-lock.json` | JSON 解析 |
| 镜像 digest | `infra/docker-compose*.yml` 的 `image:` 行 | 正则 |
| Python 解释器版本 | `.python-version`；容器 `Dockerfile` | 文本 |

**核对命令**（任一机器，无需装依赖）：

```bash
python -c "import tomllib,pathlib;d=tomllib.loads(pathlib.Path('uv.lock').read_text(encoding='utf-8'));print(len(d['package']),'个包');[print(f\"{p['name']}=={p['version']}\") for p in sorted(d['package'],key=lambda x:x['name'])]"
```

输出应与第 3.2 节逐行一致；不一致时以 `uv.lock` 为准，并更新本文件。

## 10. 版本管理约定（对应题面「注意版本管理以便环境部署及应用重现」）

1. **锁定文件必须入库**：`uv.lock`、`web/package-lock.json` 都进仓库，保证异机还原出同一套版本。
2. **容器镜像 tag + digest 双写**：只写 tag，上游重推同名 tag 会让镜像内容变化，进而让健康检查断言
   （如 `chinook` 行数、AW 对象数 80）亮红灯；digest 钉住内容，改动时显式换 digest。
3. **加/删依赖走 uv**：`uv add <包>` / `uv remove <包>`，会同步更新 `pyproject.toml` 与 `uv.lock`，一起提交。
4. **Python 版本三处一致**：`.python-version`（开发）、`pyproject.toml` `requires-python`、`Dockerfile` 基础镜像
   ——改版本时三处同步改。
