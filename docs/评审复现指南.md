# 评审复现指南（3 分钟，不需要实验服务器）

> 目的：拿到本仓库的人，在一台**没装过本项目**的电脑上，把界面跑起来，
> 并亲手验证「问题 → 事实表 → 逐行判定」这条核心链路。
> 全过程**不调用任何大模型、不联网、不需要 KAG 服务器**。

## 一、能复现什么、不能复现什么

先说边界，避免按错误的预期去试。

| 能力 | 本机可复现 | 依赖 |
|---|---|---|
| 登录、工作台、事实核验面板 | ✅ | 只需 Python |
| 冻结题库 31 题（M 20 / D 6 / B 5） | ✅ | 仓库已带 `qbank_v4.json` |
| 逐题事实表重算：拆题 → 判定 → 逐行数值 | ✅ | 仓库已带 `_records.json`（1,031 条结构化记录） |
| 判分规则、四臂汇总、补丁 diff | ✅（读，不跑） | 仓库已带 |
| KAG 问答链路（规划 → 检索 → 生成） | ❌ | 需自建 OpenSPG/KAG 0.8.0（四容器）并建图 |
| 四臂对照实验（192 次请求） | ❌ | 需上述平台 + 两个商业模型 API Key |

第二类不可本机复现，原因是环境而非权限：KAG 建图要 Neo4j/MySQL/MinIO 四容器跑满一轮，
四臂实验每臂 48 次调用、按并发 2 跑满约 40 分钟。这类实验在报告第五章给了完整读数与判据，
本指南不假装能在笔记本上重跑。

## 二、三步跑起来

要求：**Python 3.11 及以上**（`pyproject.toml` 的 `requires-python`），Windows / macOS / Linux 均可。

```bash
git clone <仓库地址> && cd evidence-qa

# 1) 只装这 6 个包。不需要 torch / OCR / 向量库
python -m pip install -r requirements-local.txt

# 2) 启动（会自动建一个演示账号并打印口令）
python scripts/start_local.py

# 3) 浏览器打开 http://127.0.0.1:8000
#    账号 demo  密码 Demo2026Local!（脚本启动时会再打印一次）
```

启动器做三件事：找一个空闲的账号库（`data/local_auth.db`）、建/重置演示账号、
起服务并把 `web/dist` 一起托管。**仓库已随附前端构建产物，所以不需要 Node/npm。**

Windows 上也可以直接双击仓库根目录的 `start-local.cmd`。

## 三、打开后看什么

1. 登录后进入工作台。左下角「事实核验」按钮会显示 `KAG 服务未连接` —— 这是**正常的**，
   因为本机没有 KAG 服务；离线判定不依赖它。
2. 点「事实核验」，左侧是冻结的 31 道题，选 `M-01`。
3. 右侧出现一张表：`F01 … 滁州学院 · 全类别合计 = 28 项`、`F02 … = 38 项`，状态「已判定」。
   这两个数与报告表 5-1 同源的题库 gold 一致（`2023 年度 28 项；2024 年度 38 项`）。
4. 换 `M-06`（山东 2016 自筹经费、青岛黄海学院）会得到 `7 项`。

这一页的关键不是数字本身，而是它上方那行说明：**证据列留空**。
没有检索就没有证据，系统不会假装有——这是本作品对「可溯源」的定义方式。

## 四、命令行直接验（不打开浏览器）

```bash
python scripts/verify_offline.py
```

只读仓库自带数据，逐项断言：题库题数、出表题数、事实行数、记录条数，
期望 `31 题 / 19 出表 / 77 行 / 1,031 条记录`。任何一项不符都会以非零退出码结束。

## 五、常见问题

| 现象 | 原因与处理 |
|---|---|
| 打开是空白页 | `web/dist` 缺文件（被裁剪过）。执行 `cd web && npm ci && npm run build` 重建 |
| 登录后立刻退回登录页 | 用 http 访问却带 Secure Cookie。启动器已设 `VERIMIND_AUTH_COOKIE_SECURE=0`；手工起服务时请一并设置 |
| 端口被占用 | `python scripts/start_local.py --port 8100` |
| 提示缺 `psycopg` | 只装了 `psycopg`，需要二进制版：`python -m pip install "psycopg[binary]"` |
| curl 访问失败但浏览器正常 | 本机全局代理拦了 127.0.0.1，加 `--noproxy '*'` |

## 六、要跑完整问答链路

需要一台能起 OpenSPG/KAG 的机器（报告附录 A 与资源清单 v1.0 列了四个容器与版本），
建好图后在仓库根目录放 `.env.local`，写入 `KAG_BASE=http://<你的地址>:8887` 与 `KAG_APP_ID`，
再用 `start-kag.cmd`（或 `python scripts/start_local.py`，它会识别 `KAG_BASE`）。
建图脚本与参数见 `docs/` 下的实验记录；四臂跑批需要两个模型 API Key，不随仓库分发。
