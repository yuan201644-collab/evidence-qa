# EvoOntology 是否值得接入项目：阶段结论 v0.1

> **已被 v0.2 取代，不要单独引用本版 SQL 正确率。** 后续独立 Gold 语义审计判定 4 题不确定；有效题子集复评分见 `docs/EvoOntology任务4接入价值阶段结论_v0.2.md`。本版保留用于记录发现和修订过程。

日期：2026-10-04。结论范围：当前 AdventureWorks 任务4实验；不是赛事分数保证，也不是所有业务库上的通用结论。

## 结论

**目前不建议把完整 EvoOntology 按需方案接入正式问数主链路。** 独立题上它明显改善了“定位哪些表和字段”，但尚未改善最终 SQL 答案正确率；并且请求次数、延迟更高。可以保留它作为隔离分支里的候选优化继续验证，不能把“字段定位更准”说成“问数答案更准”。

## 主要证据

| 测量环节 | A：全量结构、无知识 | C：按需检索知识并裁剪结构 | C−A |
|---|---:|---:|---:|
| 独立题字段定位召回率（28 题，一次/题） | 62.76% | 89.29% | **+26.53 个百分点**，95% 题级配对 bootstrap 区间 [+3.57,+47.96] 个百分点 |
| 最终 SQL 结果集正确率（28 题，每题每臂运行两次，共 56 次/臂） | 47/56（83.93%） | 45/56（80.36%） | **−3.57 个百分点**；按题先平均两次后，95% bootstrap 区间 [−17.86,+10.71] 个百分点 |
| 完整词元数 | 474,756 | 203,676 | C 少 **57.1%** |
| 模型请求次数 | 56 | 112 | C 为 2 倍（多一次检索规划） |
| 中位端到端耗时 | 1.89 秒 | 4.90 秒 | C 为 2.60 倍；均值约为 3.55 倍 |
| 最终 SQL 通过只读检查并执行 | 56/56 | 56/56 | 本轮未发现安全闸门拒绝或执行失败，但这不等于生产安全已被充分验证 |

SQL 正确率的区间跨过零，样本无法排除中等幅度的正负差异；点估计轻微偏向 A。当前证据因此**不支持接入完整方案**，也不能声称已证明 C 一定更差。更明确的是：字段召回收益没有转化成当前测量到的结果集正确率收益，且延迟和请求数上升。省词元是成本优势，但单独不足以抵消准确率证据不足与响应变慢。

另一个限制是前一轮 v0.3d 在旧 32 题上的 C−A 字段召回差为 −1.17 个百分点，区间 [−23.05,+20.70]；新独立 28 题上的定位差却为 +26.53 个百分点。题集间方向变化说明效果可能强烈依赖题目类型，不能挑新题集的好结果当普遍结论。SQL 后续实验的查询内字段覆盖代理差为 +5.04 个百分点，但最终结果正确率仍无正向证据，正说明中间指标不能替代端到端答案指标。

## 可信度与审计说明

- 独立题由编题者在查看先前模型结果前制作；另一位 Gold 审阅者复核题面、字段 Gold、关系键和只读见证 SQL；与先前题集做去重。数据集 SHA-256 为 `01ab76effa0232036466fc9e20bd809b6860e11345e3939f95bab559505950c7`。固定 AdventureWorks 镜像含 80 个结构对象，28/28 条 Gold 查询只读执行成功且返回非空结果。
- 字段定位复验在独立题结果揭盲前已冻结题集、代码、模型公开名、端点、请求配置和数据库指纹。SQL 结果复验是看到定位结果之后设计的后续实验，故明确标为探索性，未冒充原预注册确认性试验。Gold 未进入模型 prompt；A/C 同题配对、题内随机臂顺序，每题每臂运行两次；未重跑、替换或删除任何失败题。
- **评分口径曾出现缺陷，已经完整披露。** 首个离线评分器误把按列名保存的行对象当成数据值；同时把 Gold 为稳定展示添加的 `ORDER BY` 当成题面排序要求。最初的 112/112 全失败报告已原样保存在 `result_equivalence_report_invalid_order_rule.json`，不得引用为模型结果。独立盲审者仅看题面及规定字段、没有读取模型输出，逐题判定本题没有明确要求行排序；第二次修正同时按列名还原真实值，并依据题面排序语义比较。修正规则在看到模型输出后才制定，所以复算值是**透明的事后探索性复评分**，证据等级低于预先冻结的主试验。过程写在 `docs/EvoOntology任务4SQL结果判定口径修订_v0.1a.md`；未发起新模型调用。
- 两次运行不等于两倍样本。区间以 **28 道题**为重采样单位，每题先对两次运行取平均，避免把同一道题伪装成独立样本。独立题 SQL 结果仍然数量有限，区间较宽。
- 对外服务只暴露模型公开名称与调用端点，没有可锁定服务端权重版本的证据；temperature=0 也不保证服务端完全确定。本结论只适用于这 28 道题、此数据库快照、这份知识快照和本次模型服务，不能外推成竞赛得分或真实生产收益。

## 下一步

先不要扩大完整方案接入。若团队还要验证其价值，下一轮应先固定语义排序评分规则，在更大的全新题集上比较 A 与 C 的**最终答案正确率和端到端延迟**，并单独拆分“只加知识、不裁剪结构”与“只裁剪结构”两项，判断收益究竟来自哪一环。按本轮 28 题的题级差值标准差作简单正态近似，检出 +10 个百分点约需 116 道全新配对题；这只是小样本 pilot 的粗略估计，实际应按分层题目和预定统计检验重新做功效计算。只有确认性题集上的答案准确率达到预设实际增益门槛、区间下界大于零，且延迟可接受时，再考虑隔离小流量试接。
