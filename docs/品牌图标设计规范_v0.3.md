# 知证 VeriMind 品牌图标设计规范

版本：v0.3  
更新日期：2026-10-12  
状态：双源合证主标志试行；功能图标延续折面系统。

## 设计定位

主标志强调项目的核心特征：两个来源汇合，并形成可核验的结论。视觉由左右两片来源面、页签折角和中心核验符号组成；结构化数据与文档来源通过中心关系结合。它不要求观者逐个部件读出具体技术含义。

功能图标继续使用“折面”视觉语言，以切角多边形、斜向折痕、错位层叠和留白建立一致性。较具体的模块含义由名称和说明承担，不靠图标单独表达。

## 视觉规则

1. **主标志构形**：左右来源形态相向汇合；左侧保留页签折角细节；中心核验记号必须与整体轮廓结合，避免像单独悬挂的徽章。不得额外加入数据库圆柱、机器人、放大镜等常见素材。
2. **功能图标**：优先使用切角多边形、斜向折痕、错位层叠和负形。单个功能图标控制在 2–5 个主要面，不堆装饰线或微小符号。
3. **颜色**：品牌蓝 `#315bc7`、深蓝 `#254ba6`、浅蓝 `#8fa8e9`、核验青绿 `#168b82` / `#55d4c3`。单个图标原则上不超过 3 种颜色；KAG 研究支线使用紫色 `#80649b` 系列，避免与主线混淆。
4. **画布**：功能图标使用 48×48 SVG，保留约 3 px 安全边距。主标志使用 128×128；应用图标可在主标志外加圆角底板，单色版不依赖彩色背景。
5. **小尺寸与反白**：界面功能图标常以 29–44 px 显示；主标志需检查 16/32 px、单色、反白和灰度形态。微小细节不得承担关键轮廓识别。
6. **克制与可复用**：不使用照片、渐变、阴影或纹理作为图标主体；不从现成商标或图标库描摹图形。KAG 图标只表示研究支线，不表示已接入默认问答链路。

## 资产位置

- FEVA 整体架构图标、机制与能力图标及数据库目录支持图标：`web/public/brand/icons/`
- 图标总览：`docs/brand/图标总览.html` 与 `docs/brand/图标总览.png`
- 前一版折面主标志归档：`docs/brand/mark_history/`

## 使用与验收

- 前端、架构图、报告和演示材料引用 `web/public/brand/` 的同一套 SVG，不要复制后另行改色或变形。FEVA 整体架构图标用于工作台架构入口；机制与能力图标仍分别对应具体模块。
- 图标不表示功能状态或验收结论；状态须配文字、标签或数据说明。
- 修改后检查 SVG 可解析、图形未越界；主标志在 16/32 px、单色和反白下仍有清楚轮廓。运行前端构建与 UI 检查，并目视检查图标总览和架构图。
- 通用交互图标仍使用 `web/src/components/AppIcon.vue`，不属于品牌图标族。
