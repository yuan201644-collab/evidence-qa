# 知证 VeriMind 品牌图标设计规范

版本：v0.2  
更新日期：2026-10-12  
状态：折面方向已选定；已更新项目主标志与 8 个功能图标。

## 设计方向

主视觉采用“折面”：以不对称多边形、切面和留白形成抽象符号。目标是让图标先显得精致、容易记住，再由旁边的名称解释模块含义；不把每个图标都画成数据库、文档、放大镜等直白小插画。

方向来自品牌视觉提案中的“折面”概念。三款概念稿保留在 `docs/brand/concepts_20261012/`，供回溯；本规范和正式资产以折面方向为准。

## 视觉规则

1. **共同构形**：优先使用切角多边形、斜向折痕、错位层叠和负形。一个图标控制在 2–5 个主要面，不堆装饰线或微小符号。
2. **颜色**：品牌蓝 `#315bc7`、深蓝 `#254ba6`、浅蓝 `#8fa8e9`、核验青绿 `#168b82` / `#55d4c3`。单个图标原则上不超过 3 种颜色；KAG 研究支线使用紫色 `#80649b` 系列，避免与主线混淆。
3. **形状与画布**：功能图标使用 48×48 SVG 画布，保留约 3 px 安全边距。主标志使用 128×128 画布；应用图标可在主标志外加圆角底板，材料中的单色版不依赖彩色背景。
4. **小尺寸**：界面图标常以 29–44 px 显示；favicon 另做小尺寸检查。切面不应窄到缩小后消失，也不能依赖相邻颜色差异表达关键形状。
5. **一致性**：功能图标允许有不同轮廓，但共享折面、色阶和留白逻辑。图标与相邻文字配合传达具体功能，避免用图形单独承载过多语义。
6. **克制**：不使用照片、渐变、阴影、纹理或复杂描边作为图标主体；不从现成商标或图标库描摹图形。KAG 图标只表达研究支线，不表示已经接入默认问答链路。

## 资产位置

- 项目主标志：`web/public/brand/verimind-mark.svg`
- 单色主标志：`web/public/brand/verimind-mark-mono.svg`
- 浏览器图标入口：`web/public/favicon.svg`，引用主标志，不维护另一份独立图形
- 8 个功能图标：`web/public/brand/icons/`
- 总览页：`docs/brand/图标总览.html` 与 `docs/brand/图标总览.png`

## 使用与验收

- 前端、架构图、报告和演示材料引用 `web/public/brand/` 中的同一套 SVG，不要复制后另行改色或变形。
- 图标不表示功能状态或验收结论；状态仍须用文字、标签或数据说明。
- 调整后检查 SVG 可解析、图形未越界、主标志在 16/32 px 仍可识别，运行 `npm run build` 与 `npm run test:ui`，并目视检查总览页和前端架构导览。
- 通用交互图标仍使用 `web/src/components/AppIcon.vue`，不属于品牌图标族。
