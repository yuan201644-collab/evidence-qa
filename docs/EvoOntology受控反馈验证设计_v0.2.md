# EvoOntology受控反馈验证设计 v0.2

更新日期：2026-10-03。继承v0.1的故意错误、开发/验证/测试题号、两轮配对门槛、源端探查和边界声明。每个运行仍最多一次候选提议，不根据最终测试修改候选。

v0.1已记录注入错误导致开发销售题两轮失败、采购控制题两轮通过。候选生成被格式/边界校验拒绝，但旧控制器未保留候选草稿及具体违规项，无法审计失败字段。这是实验控制器的可观测性不足，不能归因于论文无效。旧运行保留并归档，不合并分数。

本版仅修复候选审计：明确向修改模型告知别名数量≤12、长度2–30、文本≤1200的现有边界；在校验前保存原始返回正文和解析出的提议，失败时记录具体校验原因。允许引用输入中已经提供的官方字段定义来源，仍须人工核实语义。格式拒绝与证据拒绝、配对验证拒绝分开报告。接受门槛和题集不改变，不手工修改模型提议。

证据审查由当前执行者进行，独立于结果匹配评分，不能称第三方独立盲审。若修复通过，结论只限预设知识缺陷下的机制可行性，不代表现有项目真实错误自动减少。
