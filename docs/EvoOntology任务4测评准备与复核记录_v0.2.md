# EvoOntology 任务4测评准备与复核记录 v0.2

日期：2026-10-04

## 当前结论

32 道题的 v0.2 Gold 已通过两轮独立审阅，可作为本基准封存题集。该题集是我们为实验明确设定的测评口径，不声称代表真实业务定义，也不兑换赛事分数。

本轮实验设计聚焦直接定位：A 为全量结构、无知识；B 为全量结构、整本注入知识；C 为按需检索知识并只暴露筛选后的结构。主指标是字段召回率题目宏平均，主比较为 C-A 的配对差值与问题级 bootstrap 95% 区间。解释上，C-A 是检索与结构筛选的组合效果，B-A 是整本知识注入效果。

## Gold 修订与复核

第一轮审计发现相对时间、金额口径、结果粒度、必需连接字段和关联路径等问题；按基准需要补齐定义后形成 v0.2 草案。第二轮独立审阅提出的边界已经纳入：

- task4-01 只统计有销售记录且有产品子类别归属的子类别。
- task4-04 只统计有销售地区归属的订单。
- task4-09、task4-23 同时返回薪资记录数值与支付频率，并规定不做年/月/时薪换算。
- task4-19 的日期窗口固定为 2011-05-31 至 2014-06-30。
- task4-31 保留全部 2013 年上市产品，无窗口内销售记录时记 0。

第二轮审阅结论：题目与字段 Gold 主体逻辑自洽，可以冻结；复核者仅检查题面与结构字段，没有运行数据库查询。日期边界另由本地 AdventureWorks PostgreSQL 只读查询验证。

## 数据与代码核验

只读数据检查结果：`SalesOrderHeader.OrderDate` 最早为 2011-05-31，最晚为 2014-06-30；2013 年订单头记录 14,182 条；2013 年上市产品 136 个；`TerritoryID` 为空的订单 0 条。数据库内容由本地 `ict-aw` 容器查询，查询语句见 [直接定位实验设计](EvoOntology任务4直接定位实验设计_v0.2.md) 的数据依据段落。

题集生成器另验证 32 题的表列引用均存在、列所属表均在必要表集合中、必要表在外键图中连通，且题面没有泄露物理字段名。对照评分实现已由独立盲审通过；异常、无效输出、检索失败和缺臂按零召回保留在 32 个配对单位中。

本地检查：`tests/test_evont_next_runner.py` 共 13 项通过；相关实验脚本通过 `py_compile`。包括 C 臂只暴露检索后结构、精确率/召回率、宏平均、缺失臂/异常记录处理的验证。原封存 v0.1 题集与运行目录未修改。
