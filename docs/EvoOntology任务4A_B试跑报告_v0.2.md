# EvoOntology 任务4 A/B 探索试跑报告 v0.2

日期：2026-10-04。状态：探索性试跑完成；不能作为最终接入判定。

## 结论

在完整 AdventureWorks schema 上，把 Builder 当前 16 条已核验知识直接放入提示后，总体最终 SQL 正确率比无知识基线高 **2.9 个百分点**；题级配对 95% 区间为 **−2.9 到 +8.6 个百分点**，仍包括零。10 道知识覆盖题的点估计高 **10 个百分点**，但区间为 **0 到 +25 个百分点**，样本太少，不能说增益稳定。

与此同时，加入整包知识使总词元数增加 **63.6%**，延迟中位数增加 **22.6%**。因此本轮既不能支持“整包知识值得直接接入”，也不能证明知识无效；结果给出的是一个需要独立确认的覆盖题正向信号。下一步应在新题上确认覆盖题收益，再决定是否测试按需检索以控制成本。

## 实验条件与题组

- A：AdventureWorks 完整 schema，无 Builder 知识。
- B：同一完整 schema，加 Builder `verified-v0.1` 的 16 条知识；只注入 `id/title/aliases/tables/description/mapping/constraints`。
- 数据库：实验前后对 AdventureWorks 全 schema 数据指纹；Gold 与错误变体均用只读执行器筛查。
- 题组：35 题，其中 schema 独立出题 27 题、知识覆盖定向补题 8 题；关系分层为 covered 10、adjacent 2、uncovered 23。定向题已明确标记，不能把题组整体结果解释成自然流量分布。
- 每题每臂两次独立请求，共 140 条原始记录；统计单位为题，每题重复先在臂内平均。
- 题面、Gold 与错误变体经过独立盲审；盲审者未查看知识包、模型输出或数据库校验结果。离线评分器的 12 个校准样例全部通过。

## 结果

| 指标 | A：无知识 | B：整包知识 | 差异 |
|---|---:|---:|---:|
| 最终 SQL 正确 | 61/70（87.1%） | 63/70（90.0%） | +2.9 个百分点（题级 95% 区间 −2.9 至 +8.6） |
| 输出列契约通过 | 70/70 | 70/70 | 0 |
| 总词元 | 606,570 | 992,197 | +63.6% |
| 延迟中位数 | 1,915 ms | 2,347 ms | +22.6% |
| API 调用失败 / 长度截断 | 0 / 0 | 0 / 0 | — |
| 用量记录完整 | 70/70 | 70/70 | — |

知识覆盖层的题级差异为 +10 个百分点（B 胜 2 题、平 8 题、A 胜 0 题）；95% 区间 0 至 +25 个百分点。邻近层仅 2 题，不能用于可靠推断。未覆盖层差异为 0（B 胜 1、平 21、A 胜 1）；区间 −6.5 至 +6.5 个百分点。

总体 4 道非平局题为 S01、U06、U17、U33：B 在 S01、U17、U33 的两次平均正确率更高，A 在 U06 更高。每个模型请求均收到完整提示、用量记录完整，70 次/臂均无长度截断或请求错误。词元增长来自 B 提示本身包含整包知识，而非额外模型调用。

## 可信度边界

1. 这是探索试跑，不是独立确认；所有 35 题永久排除在后续确认集外。
2. 总样本仅 35 个题级单位，覆盖层只有 10 题。每题两次重复不能当作额外独立样本。
3. 8 道题是按知识覆盖领域定向补充，覆盖分层可提示机制，不能代表项目自然问题比例。
4. 题级 bootstrap 区间衡量本题组内不确定性；模型服务未提供可冻结的权重修订号，结论限于记录的端点和日期。
5. 固定库上 Gold 可执行、错误变体可区分及盲审通过，提高了题目可信度，但不等于覆盖所有真实业务数据分布。
6. 本实验检验的是“当前已核验知识直接注入提示是否改善最终 SQL”，不是 Builder 自动建知识的准确率，也不是 EvoOntology 论文完整的演化与检索系统。
