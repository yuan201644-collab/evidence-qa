# EvoOntology 任务4 A/B 试跑设计 v0.2

日期：2026-10-04。状态：候选阶段；题面已按盲审意见修订，待最终盲审后才能封存和调用模型。

## 目标与范围

先回答一个窄问题：在 AdventureWorks 的完整数据库结构都提供给模型时，额外加入 Builder 当前 16 条业务知识，是否改善最终 SQL 答案。A 是完整结构、无知识；B 是相同完整结构加知识包。该对照测“直接把已核验知识放入提示”的效果，不等于论文完整的 Builder、演化器与按需复用形态，也不测知识构建器本身的准确率。只有知识确有收益后才进入检索/结构裁剪对照。

本轮 B 提示纳入知识条目的 ID、标题、别名、相关表、描述、映射和约束；不纳入 evidence_refs 与 probes。这一字段边界沿用现有实验运行器，后续结论只适用于这些可直接指导 SQL 的核心字段。

## 当前题组候选

组合题集当前有 35 题：27 道来自只看 AdventureWorks schema 和旧公开题目的独立出题者；8 道由主 agent 指定知识覆盖领域后定向补充，并明确标记为非盲出题。当前静态关系标签为 covered 10、adjacent 2、uncovered 23。标签规则：covered 表示知识条目直接陈述了该题必要的映射、公式或约束；adjacent 表示共享表/连接/粒度概念但问题指标不同；uncovered 表示本知识包没有直接概念。U17/U18 明确按 BOM 全部历史关系统计，不按有效期过滤；U19 的 StartDate 含当天、EndDate 不含当天、空 EndDate 持续有效规则已写入模型可见题面。S01 已把折扣金额口径限定为折扣明细行，E02 按 DepartmentID 区分部门实体，U33 明确按 Employee.CurrentFlag 判断在职。

候选阶段数据库只读检查显示：35 个 Gold 均可执行且非空；35 个错误变体均在当前快照产生不同结果；SQL 实际列名和题目输出契约逐列一致。原 40 道独立候选中排除 13 道（其中包括在该快照与错误变体结果相同的题和与 Builder/旧题近重复的题）；定向补充 12 题中排除 4 道近重复题。评分器另以 12 个离线案例校准并全部通过。此检查不证明 Gold 业务语义正确，因此最终门槛仍是对准确 35 题版本的独立盲审题面、Gold、旧题重复和输出契约。

## 实验与口径

- 每题在 A、B 两臂各生成两次 SQL，合计 140 次计划生成调用；同一道题的重复调用先在臂内平均，题目是统计单位。
- 固定模型公开标识、temperature=0、系统提示、只读执行器、数据库镜像/数据指纹、完整 schema、知识包 SHA-256 和调用重试策略。臂顺序按题和重复编号确定性随机交错；每次调用是独立请求，不共享对话历史。
- Gold 与错误变体只用于离线评测，绝不发给模型。原始记录保留实际提示、模型响应、SQL、校验/执行结果、用量和延迟。
- 三个指标分开报告：SQL 结果槽位和值正确；输出列名、顺序和数量符合契约；两者同时正确的端到端通过率。顶层 ORDER BY 决定行顺序是否有意义；列顺序始终按题面契约判定；拒绝 `pass_loose` 列排列作为语义正确。数值容差沿用项目评测器绝对/相对 1e-6；空值与零不同；SQL 错误和长度截断按失败保留。
- 主报告为总体 B−A 题级端到端通过率差及题级配对区间，并列 B-only、A-only、平局题数。covered、adjacent、uncovered 分层只作探索性次要结果，不将重复调用当独立样本。同步报告每臂词元、延迟、重试与失败数。

## 评分器校准与冻结条件

模型调用前，纯离线的 12 个评分校准例必须全通过：完全相同、无排序时只行序不同、有排序时行序不同、列值换位、只改别名、加/漏列、数值容差内外、NULL 与零、重复行数量、执行错误。独立盲审必须确认问题和 Gold 语义清楚，且不看任何模型输出、数据库校验结果或知识包。随后冻结题集、执行脚本、评分代码、知识资产、schema、镜像/数据指纹及报告口径的 SHA-256。

## 结论边界和后续

此 35 题只作为实验校准/探索试跑，不能直接做最终接入决策，试跑题永久排除在确认集外。试跑中包含 8 道针对知识覆盖领域的定向补充题，因此覆盖分层是探索性结果，不能据此估计真实项目题目分布下的总体收益。试跑结束先审查 A/B 是否出现 floor/ceiling、提示是否完整、Gold/变体与数据指纹是否稳定；再按题级配对差异的保守波动做样本量功效曲线。确认集重新独立构造、审题、冻结后，才对“值得接入项目”做结论。如果可行预算达不到预设的 80% 功效，报告证据不足，不把探索性结果说成稳定增益。
