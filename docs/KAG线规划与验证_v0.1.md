| graph 臂定制模块 | `unseen_relation_planning.py`（未见关系规划）、`hop_aware_citation.py`（跳感知引用）、`reference_check.py`（引用核查） |
| vector 臂 | 无上述模块（纯向量对照） |

### 2.2 判据（S4 唯一要回答的问题）

> **graph 臂相对 vector 臂，在未见语料上是否有可测的提升？**

- **是** → 图谱价值成立（S5 走接线路径）
- **否** → 图谱价值不成立（S5 走降级路径）
- 注意：对照的**公平性**依赖臂间只有「检索方式」一个变量；`vector` 臂不带 `unseen_relation_planning` / `hop_aware_citation` 是**有意的**

### 2.3 跑前必核

1. ⚠️ `cases.jsonl` 当前只有 **4 条**，与「最终 12 题」的目标对不上——**先确认题集是否补全**（或确认 12 = 4 题 × 3 臂的执行次数）
2. 环境变量 `KAG_GLM_API_KEY` / `KAG_SILICONFLOW_API_KEY` 已设为 **Windows 用户级**（2026-09-25），两把 key 均实测 HTTP 200；**运行器重启后**新进程才可见
3. 建图工作区 `build_with_vector_schema/` 的 ckpt 是否为最新语料（`AskDataS1/builder/data/` 共 32 份运行手册系文档）
