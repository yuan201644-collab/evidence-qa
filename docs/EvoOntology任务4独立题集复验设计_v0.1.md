# EvoOntology 任务4独立题集复验设计 v0.1

日期：2026-10-04。状态：冻结前设计。定位：**新题集上的方向性复验；样本量不足以支撑小增益的确认性结论**。

## 要回答的问题

在未用于前两轮提示调试的 28 道 AdventureWorks 问题上，完整按需方案 C（知识检索规划＋知识提示＋结构筛选）是否比 A（完整结构、无业务知识）更准确地定位所需字段？这项复验比较系统策略，不拆分其内部机制。

主指标是题目级字段召回率的等权宏平均；主要对比是 C−A。题集在 v0.3d 的模型结果揭示前，由独立编题者只看数据库结构编制；另一位审阅者复核 Gold、SQL，并对照封存 v0.2 题集去重。全部 28 条只读见证 SQL 在固定 AdventureWorks 容器的 `postgres` 数据库执行成功且结果非空。候选题集 SHA-256：`01ab76effa0232036466fc9e20bd809b6860e11345e3939f95bab559505950c7`。

## 预先约定

- 28 道配对题，每题 A/C 各运行一次；调用顺序由固定种子随机化。C 的检索规划、知识检索和最终定位均按现有评测程序执行，不复用旧响应。
- 运行器只把题面、归一化问题、结构或检索知识发给模型；Gold 只由评分器读取。每题每臂都保留记录。模型请求失败、JSON 无效、C 无法选出结构均计零召回；不补题、不删题、不按输出修改 Gold。
- 主指标为字段召回率。报告 C−A 题级配对差值、提升/持平/下降数和固定种子 2,000 次题级配对 bootstrap 95% 区间。表召回率、字段精确率、完整率、请求次数、词元数和耗时为次要指标。只做一个预设主比较，不从多组对比中择优。
- 工程决策门槛预先定为：C−A 点估计至少 **+10 个百分点**，且 95% 区间下界大于 0；同时 SQL 安全校验和响应成本没有明显不可接受的退步。+10 个百分点是本项目的实际收益门槛，不是赛事官方评分线。
- 达到门槛只表示可以开展隔离的小范围项目接入试验，仍需在真实 NL2SQL 任务上比较执行正确率、安全性、延迟和调用成本；不能直接合入正式主链路。未达到门槛就暂不接入，但不得称为“已证明没有效果”。

## 样本量限制

可用题集为 28 题。按 v0.3d 的 32 道探索性配对差值标准差约 0.629 作粗略正态近似，检出 +10 个百分点差异、双侧 5% 显著水平和 80% 把握度约需 311 题；检出 +5 个百分点约需 1,241 题。该估计来自小样本、单次模型运行且受解析失败影响，只用于揭示样本不足，不是精确功效分析。

因此，这 28 题可作为独立方向性复验和失败分析；只有很大的、方向一致的改善才可能越过工程决策门槛。若区间宽或未达门槛，结论必须是“证据仍不足以接入”，不能包装成等效或无效证明。
