### 3.3 对真实接口运行并保存原始输出

先建立只包含 id/question 的运行文件。以下采集命令只请求真实 /api/ask，并把请求、响应和耗时保存到独立目录；每次运行更换时间戳目录，禁止覆盖旧记录：

~~~powershell
$casePath = 'eval/cases/acceptance_20261011/rag_questions.jsonl'
$cases = Get-Content -LiteralPath $casePath | Where-Object { $_.Trim() } | ForEach-Object { $_ | ConvertFrom-Json }
$runId = Get-Date -Format 'yyyyMMdd-HHmmss'
$outDir = "eval/reports/mainline/acceptance_20261011/B-rag-$runId"
New-Item -ItemType Directory -Path $outDir -Force | Out-Null

$records = foreach ($case in $cases) {
    $watch = [System.Diagnostics.Stopwatch]::StartNew()
    try {
        $body = @{ question = $case.question; session_id = "B-$runId-$($case.id)" } | ConvertTo-Json -Compress
        $response = Invoke-RestMethod -Uri 'http://127.0.0.1:8000/api/ask' -Method Post -ContentType 'application/json' -Body $body -TimeoutSec 120
        $watch.Stop()
        [pscustomobject]@{ id = $case.id; question = $case.question; status = 'ok'; elapsed_ms = $watch.ElapsedMilliseconds; response = $response; error = $null }
    }
    catch {
        $watch.Stop()
        [pscustomobject]@{ id = $case.id; question = $case.question; status = 'error'; elapsed_ms = $watch.ElapsedMilliseconds; response = $null; error = $_.Exception.Message }
    }
}

$records | ForEach-Object { ConvertTo-Json -InputObject $_ -Depth 30 -Compress } |
    Set-Content -LiteralPath (Join-Path $outDir 'raw_answers.jsonl') -Encoding utf8
Write-Output "Saved raw run to $outDir"
~~~

运行前检查案例文件中没有答案字段；运行后确认响应记录数等于问题数。失败/超时也必须保留在记录中，不得删题后重算。输出目录保存问题文件副本、题目哈希、代码版本/工作区状态、服务配置标识（不含密钥）、语料文件清单、运行时间和错误清单。

### 3.4 逐题人工核验

每题至少核对：

1. 答案中的每个关键数字、对象名、条件或结论能否在指定原文找到；
2. 不能只看答案像不像；检查 trace 中实际检索到的文档/片段；
3. 引用文档、页码、章节与展示的片段是否来自原文，引用是否足以支持答案；
4. 题目若在材料中无答案，是否清楚说明材料不足，而不是猜测；
5. 失败、空回答、超时、不必要拒答都登记为问题，不从总数里删去。

复核人不得看 reference 后再冒充盲审。若由题目作者本人评分，应标记为作者自检；可信独立复核另由未见答案者完成。


4. 对超时、服务错误、无检索结果、空回答，界面显示清楚状态，不能伪装成成功；
5. 文档链接在本机实际打开；浏览器控制台/网络面板没有持续报错；
6. 截图应包含页面功能状态，不要带 API 密钥、.env、数据库凭据或个人账户信息。
